# Tanyu Card Builder

一个面向中文电商客服场景的开源 Skill：输入商品详情页截图、SKU 信息、卖点和商家确认资料，生成基于证据的客服知识卡。

## 能做什么

- 提取详情页中的已确认商品事实
- 规划高频买家问题
- 生成可复制的中文知识卡
- 生成条件选款与商品卡占位符
- 标记资料冲突和待确认信息
- 限制模型虚构商品功效、参数和售后承诺

## 使用方式

将整个项目文件夹作为 Skill 使用，然后提交商品详情页截图并说明：

```text
请根据这些详情页和卖点，提取已确认事实，并生成客服知识卡。
没有证据的信息不要猜，先列出待确认项。
```

## 建议提供的资料

- 商品详情页截图
- SKU、颜色、尺寸、容量或数量
- 已确认卖点和使用方法
- 适用人群与注意事项
- 商家的物流、售后和商品推荐边界

## 隐私说明

本项目不包含任何店铺私有商品资料、顾客信息、账号密钥或内部售后策略。公开使用前，也请检查自己上传的资料是否含有个人信息或商业机密。
