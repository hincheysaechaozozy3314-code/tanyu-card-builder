# 知识卡模板

## 基础问答卡

```text
# 卡片名称

【当买家询问……时】
回复两条
第一条：直接回答已确认事实
第二条：补充必要卖点、选择条件或注意事项

限制：固定回复以上两条，不添加资料中未确认的信息
```

只有一个信息点时改为“回复一条”，不要为了凑数量重复表达。

## 资料不足分支

```text
【当买家询问……但现有资料不足时】
回复一条
第一条：这个信息目前还没有确认哈，我先帮您核实下

限制：固定回复以上一条，不猜测参数或效果
```

## 条件选款卡

```text
# 规格选择

【当买家已提供明确的年龄、体重、用途或规格需求时】
回复一条
第一条：按您提供的条件，建议选择【已确认款式】哈
【待补商品卡：商品名】

限制：只推荐一个符合已确认映射的款式，商品卡只发送一次

【当买家没有提供决定选款所需的信息时】
回复一条
第一条：请问是给谁用，或者需要什么规格哈

限制：只追问一个会影响推荐结果的问题，不发送商品卡
```

## 使用方法卡

```text
# 使用方法

【当买家询问怎么用、使用步骤、一次用多少时】
回复两条
第一条：复述资料中已确认的核心使用步骤
第二条：补充已确认的频率或注意事项

限制：固定回复以上两条，不添加未确认的用量、频率或效果
```

## 测试问法

每张重点卡至少测试：

1. 标准问法
2. 口语问法
3. 简短模糊问法
4. 容易与其他卡冲突的问法
5. 超出资料边界的问法
